Voting System Documentation

A lightweight static documentation site for the Laravel-based online voting application. The actual application runs on a PHP server with login and API authentication enabled.

This GitHub Pages page is documentation only. It does not host the Laravel application.

Key Features

Secure Authentication

Web login and Sanctum bearer token API security for protected actions.

Election Management

Admin tools to create elections, add candidates, and manage voting lifecycle.

Results & Reports

Export votes and analytics in CSV, JSON, and HTML formats.

API Authentication

Protected operations require a Bearer token from `POST /api/login`.

# Login
curl -X POST http://localhost:8000/api/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@example.com","password":"password"}'

# Cast a vote
curl -X POST http://localhost:8000/api/votes \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"election_id":1,"candidate_id":2}'

# Logout
curl -X POST http://localhost:8000/api/logout \
  -H "Authorization: Bearer YOUR_TOKEN"
